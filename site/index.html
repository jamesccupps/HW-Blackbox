HW Blackbox

A hardware monitor and black box for Windows. For the question Windows leaves open: why did the PC switch off, or why did that app close?

Download for Windows Source on GitHub

Free and open source (MIT) · 64-bit Windows 10 or 11 · runs locally, nothing leaves your PC

The dashboard, here over made-up demo data.

What it records

Every sensor, every 5 seconds

CPU, motherboard sensor chip, fans, GPU (NVIDIA through NVML; AMD and Intel through LibreHardwareMonitor), load and memory, with minimum, maximum and average.

The rails, four times a second

+12 / +5 / +3.3 V, Vcore, SoC, CPU power and temperature, on their own high-priority thread. Each row is on disk before the next is taken.

A report after every power-off

When the PC really went down (the last logged row, not Windows' guess), how long it was off, and the last two minutes of readings.

Apps closing and crashing

Starts, exits and exit codes in words for the apps you choose, and an incident report with the last three minutes of everything.

Windows' own records

Crashes, hangs, display driver resets, who asked for a shutdown or restart, sign-ins and sign-outs, sleep, updates waiting for a restart, and the errors the CPU, memory and PCIe report.

Ports, disks and drives

Who listens on which port, and clashes; every drive's free space, with a warning when the Windows drive fills up fast; each drive's health, temperature and wear.

A closer look

Built to keep running

A real Windows service

Runs from boot, whether or not anyone signs in, and Windows restarts it within seconds if it ever fails.

A dead man's switch

If any part of it stops moving, a native timer ends the service so Windows starts it fresh, even when Python itself is stuck.

It tells you

A Windows notification for a power-off, a crash, a hardware error, or something that stopped working. If you run Home Assistant, an optional add-on sends it a status every minute.

Install

  1. Download HWBlackbox-win64.zip and unzip it.
  2. Double-click Setup.exe and allow admin rights: Windows' prompt names the publisher, James Cupps. If the PawnIO driver isn't installed (the CPU and motherboard sensors need it), it offers to install it: press Y.
  3. Open HW Blackbox from the Start menu.

Each release lists the zip's SHA-256, and is built on GitHub and signed by James Cupps: the installer checks every file against a signed catalog. It updates itself from its page (click Update), or run a newer Setup.exe: either keeps your settings and history.

Private by design

  • The dashboard listens on 127.0.0.1 only. Nothing leaves the PC unless you set up the Home Assistant add-on, and then only a status goes to your own server.
  • The app in front is kept for three minutes only, copied into a report after a crash or a shutdown. Each user's own records are in a folder only they can read.
  • The program and its Python live in Program Files, where only admins can write, because the service runs as SYSTEM.
