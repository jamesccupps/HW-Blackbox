# HW Blackbox 1.0.11

Uninstall from Settings, and laptops install cleanly. The settings and the history carry over.

### Installed apps

- **HW Blackbox is listed in Settings → Apps → Installed apps**, with its version, size and links. Its
  **Uninstall** asks Windows for an admin, removes the service, the agent's task, the program, the shortcut and the
  entry, and shows what it did; the window closes by itself after 15 seconds (or stays, with any warnings).
- **The data stays** in `C:\ProgramData\HWBlackbox` (logs, reports, settings), as with `Uninstall.cmd`. Delete the
  folder to remove it too, or run `install.ps1 -Uninstall -RemoveData`.
- **`Uninstall.cmd` works from `C:\Program Files\HWBlackbox` too.** Run from there, it was removing the folder it ran
  from: it could leave the folder behind (still the process's current folder) and end with "The batch file cannot be
  found". It now leaves the folder first, and ends cleanly.

### Fixes

- **A click no longer freezes the install or update window.** Windows' QuickEdit starts selecting text on a click, and
  while it selects, the window's program waits: an update looked stuck at its last step until the window was closed.
  QuickEdit is now off in these windows, and the last step says what it's waiting for (the service's first readings,
  usually 10-40 seconds).

- **A laptop's install no longer ends "DONE WITH PROBLEMS: no rail voltages".** The installer's last check took no
  rails for a fault; a laptop (or a board whose sensor chip can't be read) has none to read. It says so instead. With
  1.0.10's updater this also kept the update window open, showing a problem that wasn't one.

### Install or update

From 1.0.10: the page offers this version; click **Update**. From 1.0.9 or earlier: download **HWBlackbox-win64.zip**
below, unzip it, and double-click **`Install.cmd`**. An update keeps the settings and the history. New here? See
[Install](https://github.com/jamesccupps/HW-Blackbox#install): it offers the PawnIO driver if it's missing.
