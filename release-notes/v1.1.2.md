# HW Blackbox 1.1.2

1.1.1 as it was meant to be: Setup.exe and the installer script are signed by James Cupps, a catalog he signed covers
every file in the release, and the release is built on GitHub. Nothing else changed. The settings and the history
carry over.

1.1.1 itself couldn't be installed: 81 of the Python cache files in its zip were rewritten after they had been
checked, so its installer refused it every time (safely: it changed nothing). It's withdrawn. From this version, the
release's zip is unpacked and checked the way the installer checks it before the release is made.

### Signed

- **Setup.exe** replaces Install.cmd. Double-click it: Windows' own prompt asks for an administrator and names the
  publisher, **James Cupps** (verified), instead of an unknown script. It runs the installer in its window, so the
  report shows as it happens.
- **Every file** is in a catalog, `HWBlackbox.cat`, signed by the same publisher. The installer checks every file
  against it before anything is installed (as well as against the release's manifest, as before), and Setup.exe runs
  only an installer script signed by the same publisher: a file changed after the release was made is refused.
- **Updates from the page** install only a release signed by James Cupps, from this version on: the next version's
  installer and catalog are checked before it runs.
- **Built on GitHub**, from the tagged commit, with the packages pinned by hash and the bundled libraries from their
  NuGet packages, checked by hash. Signing is Azure Artifact Signing, through GitHub's own sign-in: no password or
  key is kept anywhere. The release's Python is 3.12.10.

### Check the download

```powershell
Get-FileHash .\HWBlackbox-win64.zip -Algorithm SHA256
```

SHA-256: `{SHA256}` (also in `SHA256SUMS.txt`, below).

Where it came from, with GitHub's CLI: `gh attestation verify HWBlackbox-win64.zip --repo jamesccupps/HW-Blackbox`.
Unzipped, `Get-AuthenticodeSignature .\HWBlackbox\Setup.exe` says **Valid**, signed by James Cupps.

### Install or update

From 1.0.10 or later: the page offers this version; click **Update**. From 1.0.9 or earlier: download
**HWBlackbox-win64.zip** below, unzip it, and double-click **`Setup.exe`**. An update keeps the settings and the
history. New here? See [Install](https://github.com/jamesccupps/HW-Blackbox#install): it offers the PawnIO driver if
it's missing.
