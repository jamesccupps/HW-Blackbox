# HW Blackbox 1.0.7

A history of which programs used the CPU, and a fix for a busy core slowing the rail readings. The settings and the
history carry over.

### New: CPU by program, over time

Windows keeps no history of which program used the CPU: Task Manager only shows now. HW Blackbox now logs every
program's CPU use each minute (`logs\cpu_YYYYMMDD.csv`, kept 183 days). It comes from the process list the service
already takes every 2 seconds, so it costs next to nothing.

- **The Processes tab** charts it over 1 hour to 7 days. Hover anywhere on the chart to see the busiest programs at
  that moment, and click a program in the table to put it on the chart or take it off.
- A program is all of its processes together (a browser's dozens are one row). There's also a row for **System
  interrupts**, the time the processors spend on drivers' interrupts, which Windows charges to no program.
- **The Overview** names the busiest program of the last hour.
- **App incident reports** list the busiest programs of the last 3 minutes.

### Fixes

- **A busy core no longer slows the rail readings.** Reading the CPU's sensors means visiting each core in turn. On
  the PC this was built on, one core was kept busy all night, most likely by the Windows desktop compositor, which
  runs at a higher priority than HW Blackbox. Every CPU read waited for that core, the rails were read on the same
  thread, and they dropped from 4 readings a second to about 2. The CPU now has a thread of its own, read once a
  second, and the rails never wait for it. The rails log's CPU columns hold the newest of those once-a-second
  readings.
- **A slow rails lane is no longer a "problem".** It sent Home Assistant alerts ("The rails lane is slow") that read
  like a fault in the power, when the rails were still being read and were fine. It's now a note on the Overview.
  A rails lane that stops altogether is still a problem.
- **When the CPU's sensors are held up,** the problem now says so ("No CPU readings for 42 s: reading the CPU's
  sensors is held up"), instead of blaming the sensor driver.

### Install or update

Download **HWBlackbox-win64.zip** below, unzip it, and double-click **`Install.cmd`**. An update keeps the settings
and the history. New here? See [Install](https://github.com/jamesccupps/HW-Blackbox#install) (the PawnIO driver
first).
