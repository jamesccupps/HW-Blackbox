# HW Blackbox 1.0.4

The first public release of **HW Blackbox**: a hardware monitor and black box for Windows. It records every sensor,
the voltage rails four times a second, power-offs, app crashes and exits, shutdown requests, ports and disk space,
from boot, whether or not anyone signs in. You read it all in a local dashboard, and optionally in Home Assistant.

### Install

1. For the CPU and motherboard sensors, install the PawnIO driver first: `winget install namazso.PawnIO`.
2. Download **HWBlackbox-win64.zip** below and unzip it.
3. Double-click **`Install.cmd`**. It asks for admin rights, installs the service and the agent, and shows what it
   did.
4. Open **HW Blackbox** from the Start menu (or `http://127.0.0.1:9070/`).

Running `Install.cmd` again later updates it and keeps the settings and the history. `Uninstall.cmd` removes it and
keeps the data.

### Check the download

```powershell
Get-FileHash .\HWBlackbox-win64.zip -Algorithm SHA256
```

SHA-256: `f9ecfe5b253f6c65628418a2f397c240d3d8f962551638d537e1a9096b27bd62`

The installer then checks every file against the release's manifest. The scripts aren't code-signed, so Windows
SmartScreen may warn the first time you run `Install.cmd`.

### What it records

- **Sensors:** every reading LibreHardwareMonitor finds, every 5 s; the +12/+5/+3.3 V rails, Vcore, SoC and CPU
  power 4 times a second. Every row is on disk before the next is taken, so the last seconds before a power loss
  survive.
- **Power-offs:** at the next boot, a report with when the PC really went down (the last logged row, not Windows'
  guess), how long it was off, and the last two minutes of readings.
- **Apps:** starts, exits and crashes of the apps you choose, with what the exit code means, and an incident report
  with the last three minutes of everything.
- **Windows:** crashes, hangs, display driver resets, who asked for a shutdown or restart, sessions, sleep, and a
  Windows update waiting for a restart.
- **Ports** (who listens where, and clashes), and **disk space** for every drive, with a warning when the Windows
  drive fills up fast.

Requirements: Windows 10 or 11, 64-bit, and an administrator account to install. It's been tested on one PC so far
(Ryzen 5 5600G, B550, RTX 3060); see *Limitations* in the README.
