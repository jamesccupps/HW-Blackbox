# HW Blackbox 1.0.5

A polish release for the dashboard and the installer. Nothing changes in what's recorded or in the files it writes;
the settings and the history carry over.

### Dashboard

- **Phones and narrow windows:** no more sideways scrolling on the Power and Processes tabs. The header's four
  status chips fit on one line with short names. On Charts, the list of readings folds away so the charts come first.
  Opening a report scrolls to it, and the selected tab stays in view.
- **Layout:** the four Overview cards go 4 → 2×2 → 1 instead of leaving one card alone on a row. One or two charts
  get a taller plot. A lone fifth chart on the Power tab takes the whole row. Long tables (Sensors, Events, Ports)
  keep their column names in view as you scroll.
- **Easier to read:**
  - times like "1 h 60 min" can't happen any more;
  - events say "ran 3 h 34 min" instead of "ran 3h 34m 12s";
  - a program that restarted on its port says so ("restarted (pid 29652, now 31000)");
  - Windows Error Reporting names are in words;
  - axis labels carry only the decimals they need;
  - a rail that didn't move says "steady".
- **The rails:** each rail's chart spans at least 2 % of the rail, so the sensor chip's one-step flicker no longer
  fills the whole +5 V chart.
- **Charts:** readings that share a chart never share a colour, and tooltips work with touch and pen.
- **Incidents:** the list shows each report's title on up to two lines and its kind, with the file name in the
  tooltip. A report has a Copy button.
- **Empty and error states:** with no power-offs, the Power table says so instead of staying blank; with no sensors
  yet, so do Sensors and the Overview. When the page can't reach HW Blackbox, the status chips grey out and the time
  turns red, instead of staying green.
- **While you work with it:** the timed refresh no longer clears text you're selecting, and a Power chart's tooltip
  survives the 5-second redraw. The page stops polling while it's hidden or minimized.
- **Keyboard and contrast:** visible focus. The tabs work with the arrow keys, Home and End. Enter or Space opens a
  sensor group, an event or a report. Dim text is brighter (4.8:1 contrast instead of 3.1:1).

### Installer

- It checks for the PawnIO driver and says how to install it when it's missing. "No rail voltages" says what to do.
- It ends by saying where to open the dashboard.
- If the admin prompt is declined, `Install.cmd` says it wasn't installed, instead of showing the previous install's
  report.

### Install or update

Download **HWBlackbox-win64.zip** below, unzip it, and double-click **`Install.cmd`**. An update keeps the settings
and the history. New here? See [Install](https://github.com/jamesccupps/HW-Blackbox#install) (the PawnIO driver
first).
