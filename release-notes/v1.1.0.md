# HW Blackbox 1.0.13

Fewer false alarms. The settings and the history carry over.

### Fixed: "Windows Explorer ended" when Explorer didn't

A program that opens a folder, or starts another program, sometimes does it by running `explorer.exe`. That extra
Explorer passes the job to the one running your taskbar and quits a second later with exit code 1, which is normal
for it. HW Blackbox counted that as Explorer ending badly and wrote an incident, though the taskbar never went away
(seen when the Ollama updater started Ollama this way).

Now an Explorer that isn't the taskbar's, quitting without a crash while the taskbar's Explorer keeps running, is
listed under Events as "an extra Explorer, started to open a folder or a program", not as an incident. The taskbar's
own Explorer ending, and any Explorer crash, are still incidents, as is any Explorer ending when HW Blackbox can't tell
which one runs the taskbar.

### Install or update

From 1.0.10 or later: the page offers this version; click **Update**. From 1.0.9 or earlier: download
**HWBlackbox-win64.zip** below, unzip it, and double-click **`Install.cmd`**. An update keeps the settings and the
history. New here? See [Install](https://github.com/jamesccupps/HW-Blackbox#install): it offers the PawnIO driver if
it's missing.

### Check the download

```powershell
Get-FileHash .\HWBlackbox-win64.zip -Algorithm SHA256
```
