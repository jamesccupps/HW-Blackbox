# HW Blackbox 1.0.10

Updates from the page. The settings and the history carry over.

### New: updates

- **Once a day the page asks GitHub for the latest release.** When there's a newer one, the top of the page says so,
  with **What's new** (the release's page) and **Update**. The Overview's Service card says when it last asked, with
  **check now**.
- **Update** asks Windows for an admin (the same prompt as `Install.cmd`), then opens a window that:
  1. downloads the release's zip into `C:\ProgramData\HWBlackbox\update`, where only SYSTEM and admins can write;
  2. checks it against the SHA-256 GitHub gives for it, and the one in the release notes;
  3. unpacks it, and checks it's the version offered;
  4. runs that version's installer (which checks every file again, keeps the settings and the history, and offers
     the PawnIO driver if it's missing);
  5. deletes the download.

  Done, the window closes by itself after 15 seconds and the page reloads into the new version. If the installer
  had problems, the window stays open to show them. If any check fails, nothing is installed and the running
  version carries on.
- **Nothing installs by itself.** HW Blackbox runs as SYSTEM, so a new version goes in only when someone at the PC
  clicks Update and says yes to Windows.
- The check sends GitHub nothing but the request itself (with HW Blackbox's version in it). `updates.check: false` in
  config.json turns the daily check off; **check now** still asks when clicked.
- From an elevated prompt: `& "C:\Program Files\HWBlackbox\python\python.exe" -m hwblackbox update` (`--dry-run`
  stops before the install).

This is the first version with the updater: from 1.0.9 or earlier, update with this version's `Install.cmd`. From
here on, the page offers each new version.

### Install or update

Download **HWBlackbox-win64.zip** below, unzip it, and double-click **`Install.cmd`**. An update keeps the settings
and the history. New here? See [Install](https://github.com/jamesccupps/HW-Blackbox#install): it offers the PawnIO driver
if it's missing.
