# HW Blackbox 1.0.8

A Diagnose tab that checks what HW Blackbox has recorded and says what to do, and each program's memory, graphics
memory and GPU use over time, next to its CPU. The settings and the history carry over.

### New: Diagnose

A new tab checks what HW Blackbox has recorded, and for each thing it finds, shows what it saw and what to do about
it. It reads and suggests; it changes nothing.

- **Power-offs** in the last 30 days, with the last readings before each.
- **Programs crashing** in the last 7 days. When several different programs crash the same way, it suggests testing
  the memory and running it at stock speed, since that points at the PC rather than at one program.
- **Display driver resets.**
- **CPU and GPU heat**, with the busiest program at the hottest moment.
- **The power supply's rails** against the ATX limits.
- **A program keeping the CPU busy.** For Windows' own programs (the desktop compositor, Explorer, Defender, Search
  and others) it says what the program is and what usually fixes it.
- **A program whose memory keeps growing**, with the times it jumped. It says when the jumps came right after the
  screens changed (a remote session, a monitor, the resolution or scaling).
- **RAM and graphics memory** running full, with the biggest programs at that moment.
- **Disk space, a Windows update waiting for a restart, and uptime.**

The Overview says when Diagnose has found something, and the tab shows a count.

### New: memory, graphics memory and the GPU by program

The Processes tab's history now has four measures: **CPU**, **Memory**, **GPU memory** and **GPU**. Each shows its
leading programs over 1 hour to 7 days, with a chart and a table.

- **Memory:** each program's private memory, all its processes together. The table shows what each holds now, its
  average, the most it held and when, and how much it grew. A gigabyte or more that a program still holds is
  highlighted, since that's what a leak looks like.
- **GPU memory and GPU:** from Windows' own GPU counters (the ones Task Manager's GPU columns use), so they work for
  any make of GPU. NVIDIA's own interface can't tell programs apart on Windows.
- The log is now `logs\programs_YYYYMMDD.csv`, a row per program a minute with all four measures. 1.0.7's
  `cpu_YYYYMMDD.csv` is still read, so the CPU history carries on unbroken.

### Fixes

- Links to a view on the Processes tab (`#processes:mem`) open that measure and scroll to it.
- **A screen change that never happened** is no longer recorded each time the session agent starts (it read the
  screens before asking Windows for their real size and scaling, so the first look after its start saw them "change").

### Install or update

Download **HWBlackbox-win64.zip** below, unzip it, and double-click **`Install.cmd`**. An update keeps the settings
and the history. New here? See [Install](https://github.com/jamesccupps/HW-Blackbox#install) (the PawnIO driver
first).
