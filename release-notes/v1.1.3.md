# HW Blackbox 1.1.3

Security fixes from a review of the code, and two other fixes. The settings and the history carry over.

### Security

- **The service never follows a link in a user's own folder.** It used to check a file there and then change its
  permissions by name, and the user could swap a link in between, to make the service open up another folder,
  HW Blackbox's own data folder included. Now each file is checked and changed through one open handle, the agent's
  files are read without following links, and the same goes for the folder moved over from a version before 1.1.0.
- **The update, the installer and the Home Assistant setup get Windows' folders from Windows**, not from environment
  variables, which a program running as you can set for every program you start after, elevated ones included (one
  could even move HW Blackbox's data folder). The update's working folder is made again for SYSTEM and the
  administrators only, every time.
- **The dashboard answers only programs in its own Windows session.** With two users signed in, the other user's
  programs could press the page's buttons, which raise admin prompts on your screen, and read what it shows.
- **The signing identity, not just the name.** Setup.exe, the installer and the updater check that a release is
  signed with James Cupps's own Azure signing identity, not only by a certificate in that name.
- **A crafted command line can't stall the service.** A very long one made the search for passwords in listening
  programs' command lines take seconds, enough to have the service ended and restarted over and over.
- **The installer's report** is now `C:\ProgramData\HWBlackbox\logs\install.txt`: it was in your TEMP folder,
  written there as an admin. And it takes the dashboard's port from the agent's file only as a number.

### Fixes

- **Diagnose's hardware check** no longer fails ("A check couldn't run") when two hardware errors come in the same
  second, which is when a part reports them: in bursts.
- **The installed program no longer rewrites its own Python cache files** after an install: they're compiled so they
  never go stale, and every file stays as the release's manifest and signed catalog list it.


### Install or update

From 1.0.10 or later: the page offers this version; click **Update**. From 1.0.9 or earlier: download
**HWBlackbox-win64.zip** below, unzip it, and double-click **`Setup.exe`**. An update keeps the settings and the
history. New here? See [Install](https://github.com/jamesccupps/HW-Blackbox#install): it offers the PawnIO driver if
it's missing.
