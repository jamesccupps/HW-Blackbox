# HW Blackbox 1.0.6

A small dashboard release. Nothing changes in what's recorded or in the files it writes; the settings and the history
carry over.

### Dashboard

- **The page's version is in the header**, next to the name, so you can tell which version you're looking at.
- **After an update, an open page says so.** A strip across the top reads "HW Blackbox was updated to 1.0.7. This
  page is still 1.0.6", with a **Reload** button that keeps the tab you're on. Before, a page left open through an
  update kept running the old version until you reloaded it yourself.

  A page that's open while you install 1.0.6 is still the old one, so reload it once; from then on it tells you.

### Install or update

Download **HWBlackbox-win64.zip** below, unzip it, and double-click **`Install.cmd`**. An update keeps the settings
and the history. New here? See [Install](https://github.com/jamesccupps/HW-Blackbox#install) (the PawnIO driver
first).
