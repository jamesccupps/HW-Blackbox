# HW Blackbox 1.0.6

Security fixes from an outside review, plus a small dashboard change. Nothing changes in what's recorded or in the
files it writes; the settings and the history carry over. **Updating is recommended**, above all on a PC with more
than one account.

### Security

These need someone signed in to the same PC with an account of their own. On a PC with one account, they don't
apply.

- **Two ways a standard account could run code as SYSTEM are closed.**
  - The service, starting a stopped session agent again, used pywin32's COM cache in `C:\Windows\Temp`, where any
    account can create files. The cache is now in the program's own folder, which only admins can change, and the
    service won't use COM if it's anywhere else.
  - On a first install, the installer created the data folder's subfolders before locking it down, and kept a data
    folder someone else had made. Now the folder is made with its final owner and permissions before anything goes
    in it. A folder someone else made first, or a link to somewhere else, is moved aside rather than used. The
    service won't write through a link, and `install.ps1 -Uninstall -RemoveData` no longer follows one.
- **Another account can't keep the service from starting.** It used a lock name any account could take first. Started
  by Windows, the service no longer needs one.
- **The Events tab:** a session folder (which every account can create) can no longer pass itself off as the service,
  and one damaged line can no longer break the tab for everyone.
- **Command lines:** the Ports page and its files hide password-like values (`--password ***`,
  `https://user:***@host`), since every account can read them.
- **App reports:** at most 20 an hour, since crash records in Windows' log can be written by any program. Old ones go
  after 183 days, like the records; power-off reports are kept.
- **The dashboard:**
  - it refuses data requests from other websites;
  - a chart request can't ask for one reading thousands of times over (that could use gigabytes of memory);
  - a program holding the dashboard's port can no longer hang the session agent.
- **Home Assistant:** a redirect is reported as an error instead of being followed, so the token isn't sent on to
  wherever it points.
- **A network share in a program's path** is no longer looked at by the service.

### Fixes

- **The power-off check doesn't depend on Windows' display language** any more. It read the English "Date:" label in
  Windows' event text, so it would never have written a power-off report on Windows in another language.
- **The power-off check runs first,** without waiting for the sensors to open, so a slow sensor driver after a power
  loss can't hold up its report.
- **A typo in `config.json`** no longer stops the service, for example `"interval_s": "fast"`. A setting of the wrong
  kind keeps its default, and the Overview names it.

### Dashboard

- **The page's version is in the header**, next to the name.
- **After an update, an open page says so,** with a **Reload** button that keeps the tab you're on. A page that's
  open while you install 1.0.6 is still the old one, so reload it once; from then on it tells you.

### Install or update

Download **HWBlackbox-win64.zip** below, unzip it, and double-click **`Install.cmd`**. An update keeps the settings
and the history. New here? See [Install](https://github.com/jamesccupps/HW-Blackbox#install) (the PawnIO driver
first).
