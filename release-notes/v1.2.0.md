# HW Blackbox 1.2.0

Every "something stopped working" notification can now fire, a new version is announced, laptops get a fast log
with something in it, the clock can't wipe the history any more, and five new things to look at: a blue screen's own
record, the firmware slowing the CPU, a laptop's battery while asleep, a report as one zip, and a chart's moment on
the Events tab. The settings and the history carry over.

### Fixes

- **Notifications for problems whose numbers move.** A problem was known by its whole text, and most of them carry a
  number that changes every minute ("the sensors aren't logging, last sample 3 min ago", the Windows drive filling
  up). The text never stayed the same for the minute a notification waits, so these were never announced, the drive
  filling up among them. A problem is now known by its words without the measurements. And a problem already
  announced is no longer announced again a minute after the agent restarts.
- **A new version is noticed with the page closed.** Only the page asked GitHub for a newer release, so a PC whose
  page nobody opened never heard of one. The session agent now asks once a day, and a Windows notification says when
  a new version is out, once for each (Settings tab: "A new version of HW Blackbox is out"). `updates.check: false`
  turns both off.
- **The fast log on a laptop.** With no board sensor chip, the 4-a-second log held only timestamps, and still synced
  to the disk 4 times a second, on battery too. It now has the CPU's power and temperature, once a second.
- **A clock that jumps forward can't delete the history.** Each clean-up counted back from today's date, so one
  record written while the date read months ahead deleted every day file. Nothing is deleted now until a day has
  been written at the new date.
- **A power-off report with the clock set back.** A PC whose clock battery has run flat boots after a power cut with
  its date years back. The report had none of the last readings then. It now has them, and says the clock was set
  back.
- **Packing an old log is safe through a power cut.** The packed copy is written to the disk before the original is
  removed.
- **A log that can't be written is a problem** ("is the drive full?"). It showed nowhere, or as the rails being "read
  less often".

### New

- **A blue screen's own record in the power-off report:** the stop code's four parameters, where the dump was saved,
  and the crash dump files, which WinDbg opens. Windows can write that record minutes after the boot: it's added to
  the report then.
- **Slowed down by the firmware:** Windows' record that the firmware held the CPU's speed down (a heat, power or
  current limit) goes into the records, and Diagnose has a check for it.
- **Battery while asleep:** on a laptop, Diagnose says how much charge each sleep on battery cost, and what to do when
  it's too much. Sleep, waking (with what woke it) and Modern Standby are in the records.
- **Save a report as a zip:** the report, the logs of its day and the status, in one file to hand to someone helping.
  It holds the programs that ran, with their command lines (secrets hidden): look before posting it anywhere public.
- **From a chart to that moment:** click a point on a chart (or press Enter on it) and the Events tab opens half an
  hour either side of it, with the busiest programs of that minute.

### Smaller

- **Less written to the disk:** the live readings' file is written every 5 s only while the page is open (every
  30 s otherwise), and the ports' table only when it changes. The records are packed once they're 35 days old.
- **The agent gives its memory back** 10 minutes after the page was last used, as its charts' cache already did.
- **The page:** the Events tab's filters wrap in a narrow window (past "Hardware" they were cut off); the Overview's
  Hardware card and the Diagnose badge show at once instead of after 10 seconds; the Power tab's header no longer says
  "4 a second" twice.
- Diagnose measures time by the rows' own times (it counted every row as 5 s); the fast lane's setting has a floor of
  0.05 s; a GPU reading of 5 °C or less is left out as a misread; Windows' event times keep their time zone (a power
  loss in the hour that repeats as daylight saving ends got no report); `crash.log` is kept under 1 MB.

### Install or update

From 1.0.10 or later: the page offers this version; click **Update**. From 1.0.9 or earlier: download
**HWBlackbox-win64.zip** below, unzip it, and double-click **`Setup.exe`**. An update keeps the settings and the
history. New here? See [Install](https://github.com/jamesccupps/HW-Blackbox#install): it offers the PawnIO driver if
it's missing.
