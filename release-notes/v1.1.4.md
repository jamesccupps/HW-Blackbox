# HW Blackbox 1.1.4

A false port problem fixed, the script behind a memory spike named, and smaller fixes. The settings and the history
carry over.

### Fixes

- **Docker's ports are no longer a "problem".** Docker Desktop publishes a container's port twice: its own program
  on every address, and WSL's relay on the loopback address. Both reach the same container, but HW Blackbox called it
  "Port 25565 is held by 2 programs", for as long as the container ran. The two now count as one. A program of
  Windows' own on the same port as the relay is still flagged: the relay takes its local connections.
- **Diagnose says which script used the memory.** Python's scripts all run as python.exe, and the programs log adds
  a program's processes up, so a finding said "python.exe (26.9 GB)" and nothing more. For a program holding 1 GB or
  more, the log now also keeps its biggest process and that process's command line (with what looks like a password
  or a token hidden, as on the Ports tab), and Diagnose names it: "python.exe's biggest process: pid 34964,
  app.py (in C:\Users\...\project)".
- **Space on the Windows drive.** Diagnose's disk check looked for C:. It now takes the drive Windows is on.
- **`set` and `init --set` check what they're given.** A name that isn't a setting, or a value it can't take, is
  said and nothing is written. Before, it went into `config.json`, and the service quietly kept the default.

### Smaller

- **Home Assistant over plain http://.** Setting it up with an `http://` address outside your own network now says
  that the token would cross the internet unencrypted, every minute, and asks before taking it.
- **The programs log in a spreadsheet.** A program name or command line starting with `=`, `+`, `-` or `@` is written
  with a `'` before it, so Excel shows it as text instead of running it as a formula.
- **Settings files written at the same moment** no longer share one temporary file.
- **`install.ps1` started from PowerShell 7** stopped at its file check ("Get-FileHash is not recognized"): Windows
  PowerShell picked up 7's modules. It now uses its own, as `Setup.exe` and the updater always made it. (Found by the
  new install test, below.)

### Tested on every release

From this version, every release is installed from its own zip on a clean Windows machine before it's published:
`Setup.exe` as you'd run it, the service running and reporting, then the Uninstall from Installed apps, which must
leave nothing behind but the data.

### Check the download

```powershell
Get-FileHash .\HWBlackbox-win64.zip -Algorithm SHA256
```

SHA-256: `{SHA256}` (also in `SHA256SUMS.txt`, below).

Where it came from, with GitHub's CLI: `gh attestation verify HWBlackbox-win64.zip --repo jamesccupps/HW-Blackbox`.
Unzipped, `Get-AuthenticodeSignature .\HWBlackbox\Setup.exe` says **Valid**, signed by James Cupps.

### Install or update

From 1.0.10 or later: the page offers this version; click **Update**. From 1.0.9 or earlier: download
**HWBlackbox-win64.zip** below, unzip it, and double-click **`Setup.exe`**. An update keeps the settings and the
history. New here? See [Install](https://github.com/jamesccupps/HW-Blackbox#install): it offers the PawnIO driver if
it's missing.
